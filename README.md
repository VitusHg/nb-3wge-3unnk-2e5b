# Einsatztagebuch

Persönliche PWA. Die App liegt in `docs/` (GitHub Pages: Branch `main`, Ordner `/docs`).
Daten bleiben nur auf dem Gerät.

Einsatzstichwörter und PZC-Codes sind nicht im Repo – sie werden in der App
über *Einstellungen → Codes & PZC → JSON importieren* geladen.

Nach Änderungen in `docs/sw.js` die `CACHE_NAME`-Version erhöhen und `APP_VERSION`
(samt Datum) in `docs/app.js` auf denselben Wert setzen – sie steht unter *Einstellungen → Über*.
